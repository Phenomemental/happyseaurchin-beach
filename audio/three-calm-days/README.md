# Three Calm Days: the film's recordings

Matthew's own voice for the film on `three-calm-days.html` (spine:three-calm-days 6.52).

- `scene-01.mp3` to `scene-10.mp3`: one file for each scene, in the film's order.
- `closing.mp3`: the closing card (its heading, then 6.41 and 6.42).

Beneath each scene's line in 6.3 sits a line beginning `RECORDED:`, giving the file's name and then the exact words read, for example:

    RECORDED: scene-01.mp3 — A wave is coming. Far out, a swell began with ChatGPT in November 2022. …

The closing card's line sits beneath 6.4. The page plays a recording only while those words still match the scene's words, word by word, ignoring punctuation and capital letters. Where the words have changed since, or the file is missing, that scene is spoken in the phone's own voice.
